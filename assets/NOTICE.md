# Pink Spotify icon attribution

The optional pink Spotify shortcut assets use the `spotify` SVG glyph from the official [Spicetify CLI SVGIcons source](https://github.com/spicetify/cli/blob/v2.46.2/src/jsHelper/spicetifyWrapper/icons.js), distributed under LGPL-2.1. The original license is included as `LICENSE.spicetify.txt`.

Changes: applied pink (`#f58bbb`) to the Spotify glyph, added a dark backing circle, and rendered PNG and multi-resolution Windows ICO variants. The editable SVG source is included alongside those variants.

The Spotify name and logo identify Spotify; this extension and custom shortcut icon are independent customizations.
